# Day 1 practice hints

1. Verify `node --version` and `npm.cmd --version` before debugging lesson code.
2. Run both starters, then change one value and predict the output before running again.
3. Explain the difference between JavaScript (runtime) and TypeScript (checked source) in one sentence.
4. If a browser lesson is involved later, use `npm.cmd run dev`; do not install a global server.
