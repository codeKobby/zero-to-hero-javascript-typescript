# Lesson Template

Use this as the default shape for learner-facing lessons in this course.

## Suggested structure

1. Title and navigation links.
2. Table of contents.
3. Why this lesson exists.
4. What you should already know.
5. What you will be able to explain and do by the end.
6. The problem first.
7. Keywords and terms, each with a short plain-English meaning.
8. Topics, separated into explicit questions such as “What is a function?”, “Why is it useful?”, “What are its parts?”, and “What types or variations exist?”.
9. Step-by-step examples with a trace.
10. JavaScript and TypeScript side by side.
11. Common mistakes and how to spot them.
12. Line-by-line reading, prediction experiments, and broken-and-repaired examples.
13. Guided practice before independent practice.
14. Practice, hints, and worked solutions in separate files.
15. Check yourself summary.

## Writing rules

- Start from the learner's problem, not the syntax.
- Separate Keywords and terms from the Topics that use them.
- Give each topic a descriptive question or concept heading.
- Show one small idea at a time.
- Explain why the example works, not only what it prints.
- Keep JavaScript and TypeScript showing the same runtime idea.
- Put spoilers in `practice/hints.md` and `practice/solutions.md`, not in the lesson flow.
- Add a table of contents when the lesson has several major sections.
- End with one short mental model the learner can remember.
