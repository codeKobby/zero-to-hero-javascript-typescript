# Day 19 hints

Use only when you are stuck — the learning happens in the attempt.

1. Put the changing values in the constructor and assign them to `this`.
2. Call `tick` on one variable, then log the field on both variables.
3. A method can return strings built from `this.label` and `this.elapsedSeconds`.
4. Use `void` for a method that changes state but does not return a useful value.
5. `percentComplete` can divide two fields and `Math.round` the result.
6. A field that starts at zero can be given a default in the constructor.
